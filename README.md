# BRFSS 2015 Diabetes Health Indicators — EDA

Exploratory data analysis of the CDC's 2015 Behavioral Risk Factor Surveillance
System (BRFSS) diabetes health indicators dataset.

**Live notebook:** https://lone-wolfgang.github.io/brfss2015-diabetes-eda/

## Data

The dataset is not included in this repo. Download it from
[Kaggle: Diabetes Health Indicators Dataset](https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset)
and place the CSV in the project root before running the notebook.

## Setup

```bash
uv sync
uv run jupyter lab
```
