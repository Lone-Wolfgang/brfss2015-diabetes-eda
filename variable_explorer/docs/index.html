CDC Diabetes Health Indicators

BRFSS 2015 survey responses, one row per respondent — the same 253,680 rows and 21 predictors the rest of this site uses. Every variable is plotted below; switch the view to see how each one breaks down by outcome.

This page collapses the shared Diabetes_012 target to a binary one: 1 = diagnosed diabetes (class 2, 35,346 rows), 0 = everyone else. Note that the 4,631 prediabetic respondents (class 1, 1.8%) fall on the 0 side here, so the positive rate is 13.9% rather than the 15.8% you would get by grouping prediabetes with diabetes. The other tabs keep all three classes separate — read rates here as diagnosed diabetes only.
